# Definition of Done

A change is **done** only when every box that applies is checked. The PR template repeats this list.

## Every change

- [ ] Linked to a ROADMAP item (`M*`) or an experiment (`EXP-*`), and ROADMAP.md updated in the same commit.
- [ ] `ruff check lvx tools tests` and `pytest -q` pass.
- [ ] `python tools/check_tree.py`, `check_experiments.py`, `check_reports.py` pass.
- [ ] Docs changed with the behaviour (how-to, reference, or the experiment report).
- [ ] No personal paths, data, or upstream lightning-lm source in the tree.
- [ ] Conventional Commit message with the ID in the scope.

## An experiment moving to `approved`

- [ ] No TODO left in the frozen fields; one change per variant; the decision rule uses the noise floor.
- [ ] The user approved the spec explicitly; `lvx exp freeze --approved-by <handle>` was run.

## An experiment moving to `concluded`

- [ ] All planned runs exist (ok, failed or dirty); `summary.json` says `complete: true`.
- [ ] The standard figures are generated; the report blocks were regenerated by `lvx report`.
- [ ] TL;DR, observations, discussion, verdict, threats to validity, and failures are written.
- [ ] The verdict follows the frozen decision rule (quote it).
- [ ] `lvx report --index` was run (registry + README updated).

## A course chapter

- [ ] **Read-aloud test:** reading README.md, then the `.py` files top to bottom, without opening any other
      file, explains the idea. Every line is understandable where it stands.
- [ ] The folder is self-contained (copied helpers name their source chapter); `python tools/check_chapters.py` passes.
- [ ] The synthetic scene is something a person recognises at a glance; the money plot is at the top.
- [ ] `cd` into the folder and `python main.py` runs from a fresh clone in ≤ ~30 s with no dataset; the new
      `results/output.txt` is pasted into the README.
- [ ] README has the sections in order; `python tools/sync_course.py --check` passes. Every figure was looked at.
- [ ] Every claim on the page is asserted in `tests/course/test_<ID>.py`.
- [ ] Curriculum table (docs/learn/README.md), ROADMAP and mkdocs nav updated.

## A code change in the SE(3)-LVIO fork

- [ ] It sits behind one flag whose default reproduces the baseline (ARC-6 within 2σ of EXP-000).
- [ ] The flag is documented in the fork's config with the experiment ID.
- [ ] The submodule pointer bump is its own commit: `chore(systems): se3-lvio <sha> (EXP-NNN flag)`.
